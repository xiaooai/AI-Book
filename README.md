# AI 阅读手记

双击 `dist/index.html` 即可离线阅读，无需运行服务或启动脚本。每章的个人笔记保存在当前浏览器本地存储中，点击“保存笔记”即可。使用同一浏览器和同一文件路径可继续读取；清除网站数据、更换浏览器或移动文件可能导致笔记无法读取。旧版评论会在原浏览器、原文件地址下自动合入对应章节笔记，原数据保留。

正文保存在 `chapters/` 中，每个 Markdown 文件是一章，阅读顺序与分篇由 `book.json` 管理（文件名保留原始编号，以保持旧链接有效）。后续继续把内容发给助手即可整理入书。当前内容来自用户提供的阅读笔记，未另外核对论文。

维护方式：修改章节，或添加章节并更新 `book.json` 后，运行 `python3 build.py` 更新阅读页面。`reader.html` 为阅读界面模板，支持章节目录、字号调节和日夜模式。生成的页面包含全部正文，可以单独复制到其他设备离线阅读。

公式支持 `\( ... \)` 行内格式，以及 `\[ ... \]`、`$$ ... $$` 独立格式。生成时使用本地 KaTeX 转为浏览器原生 MathML，无需联网加载脚本或字体；单个美元符号保留为普通文字，避免误识别金额。生成页面需要 Python 3 和 Node.js，阅读页面不需要安装任何依赖。

## GitHub Pages

发布配置位于 `.github/workflows/pages.yml`，将 `main` 分支中已生成的 `dist/` 发布为静态阅读页面。在 GitHub 仓库的 Settings → Pages 中选择 GitHub Actions。更新内容后，先在本地生成页面，再提交和推送即可自动发布；在线阅读无需运行 Python 或其他服务。

在线版个人笔记仍仅保存在当前浏览器，不会上传至 GitHub。离线文件与在线网址使用不同的存储空间，笔记不会自动迁移。
