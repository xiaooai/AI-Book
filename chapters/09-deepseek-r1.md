# DeepSeek-R1：用强化学习探索推理

论文：DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning（2025）

## 01 · 让模型自己探索推理方式

这篇就是 2025 年的《DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning》。如果沿着你前面已经读过的 DeepSeek LLM → V2 → V3 往下走，R1 的研究问题发生了一个很明显的变化：前几篇主要在问“怎样把基础模型做得更强、更大、更便宜”，而 R1 开始问：**一个已经很强的基础模型，能不能不靠大量人工写好的推理过程，而是只通过强化学习，让它自己学会更长、更有效的思考方式？**这篇论文最核心的答案是：可以，而且在数学、代码、STEM 这类答案可验证的任务上，强化学习不仅能提高最终正确率，还会自然诱导出一些很有意思的行为，比如反思、检查、换思路、延长思考时间。作者甚至先做了一个非常极端的实验 DeepSeek-R1-Zero：直接从 DeepSeek-V3-Base 出发，跳过传统的监督微调，让模型只靠强化学习自己“长出”推理能力。([arXiv][1])

## 02 · 从模仿解题到奖励探索

要理解为什么这件事重要，先回忆一下过去怎么教模型推理。一个常见做法是给模型大量 chain-of-thought，也就是人类或更强模型写好的“第一步这么想、第二步这么算、第三步检查”的解题过程，然后做监督微调。这个方法很有效，但有一个根本问题：**你是在教学生模仿老师的思路。**老师写得好，学生就学得好；老师思路有局限，学生也很容易被限制在这些模式里。DeepSeek-R1 的作者因此提出一个更大胆的问题：如果一道数学题最后答案可以自动判断对错，我们为什么一定要告诉模型“应该怎么想”？能不能只告诉它“最后答对了得分，答错了不得分”，至于中间怎么思考，让模型自己探索？论文明确说，他们希望减少对人工标注推理轨迹的依赖，避免人为规定推理方式限制模型探索新的策略。([arXiv][1])

这就很像教一个学生做奥数。传统 SFT 是老师先写十万份标准解答：“看到这种题先设 x，然后列方程，然后化简。”学生照着模仿。R1-Zero 的办法更像把学生关进练习室，只给题和最终答案检查器：你可以试任何方法，只要最后答对就加分。第一次可能乱算，第二次换方法，慢慢它发现“算完以后回头检查”“发现矛盾就重新开始”“这条路太复杂就换一个角度”这些行为会提高得分，于是这些行为的概率就逐渐变大。**所以 R1-Zero 最值得记住的不是模型学会了某一道数学题，而是强化学习开始直接塑造“思考过程本身”。**论文摘要把这一点概括为 self-reflection、verification 和 dynamic strategy adaptation 的自然出现。([arXiv][2])

## 03 · GRPO：比较同一道题的不同尝试

这里就轮到你前面在 DeepSeek-V2/V3 已经见过的 **GRPO，Group Relative Policy Optimization**。它是 R1 的核心强化学习算法。费曼式地说，GRPO 不需要给每道题额外养一个巨大的“老师模型”去判断这个回答理论上应该值多少分；它会对同一道题一次生成一组答案，然后拿这一组互相比较。假设同一道题生成 16 份解答，其中 5 份最后正确、11 份错误，正确答案在组内就是“高于平均水平”的行为，于是训练会提高这些回答路径的概率，降低差答案的概率。数学上，论文把每个回答的 advantage 近似成“这个回答的 reward 减去整组 reward 均值，再除以组内标准差”。([arXiv][1]) 所以 GRPO 的关键思想不是复杂公式，而是：**不要问‘这份答案绝对有多好’，先问‘同一道题的这些尝试里，哪些明显更好’。**

## 04 · 为什么可验证奖励很重要

为什么数学、编程特别适合这种方法？因为 reward 很容易做得可靠。数学答案可以比较最终结果，代码可以跑测试用例。如果题目正确答案是 42，模型写了三千 token 推导，最后得到 42，那么我们至少很容易判断“结果对了”；如果答案是 17，也很容易判断错。**这类 verifiable reward 很重要，因为强化学习最怕 reward model 被模型钻空子。**如果让另一个语言模型评价“这个答案是不是有帮助”，模型可能逐渐学会迎合评分器而不是解决问题；论文后来确实讨论了 reward hacking，甚至展示过 reward 继续上升但 Codeforces 实际能力下降的情况。([arXiv][1]) 这也是为什么 R1 最惊艳的提升首先出现在数学、代码、STEM，而不是所有语言任务都同样巨大：越容易客观验证结果，强化学习信号越干净。

## 05 · R1-Zero 的进步与反思行为

R1-Zero 的实验结果很能说明问题。论文报告，在 AIME 2024 这类竞赛数学任务上，随着强化学习进行，R1-Zero 的 pass@1 从最初大约 **15.6% 一路提高到 77.9%**；如果再通过多次采样做 self-consistency，准确率可以到 **86.7%**。([arXiv][1]) 这里最重要的不只是“77.9 很高”，而是整个过程中并没有先给模型大量人类写好的标准推理轨迹。也就是说，**V3-Base 本来已经具备一定潜在能力，RL 像是把这些能力重新组织成更有效的长程推理行为。**你可以把 pretraining 想成一个学生已经学完数学知识，而 RL 不再主要往他脑子里塞更多公式，而是训练他“遇到难题时应该愿意多试几次、检查自己、换策略”。

论文里最出圈的就是所谓 **“aha moment”**。作者观察到，R1-Zero 训练到某个阶段以后，会在解题过程中突然出现类似“Wait, wait”这种自我打断，然后重新检查前面的推导，发现可能走错路，再换思路。论文把这种行为当作 self-evolution 的一个例子：没有人专门写规则说“第 4000 个 token 时请停下来反思”，但因为这种行为有时候能够把错误答案救回来、获得更高 reward，于是强化学习逐渐把它强化。随着训练进行，模型总体上也会使用越来越长的推理链。([arXiv][1]) 这里要谨慎理解：“aha moment”并不意味着模型突然像人一样获得了主观顿悟；它更准确的含义是，**训练过程中出现了新的可观察推理模式，而这些模式不是人工直接指定的。**

## 06 · 推理过程一定要像人吗？

这里其实引出了 R1 整篇论文最有哲学意味的问题：**推理过程一定要像人吗？**过去我们经常用人工 CoT 教模型，因为我们知道人类这么推理有效。但如果最终评价标准只是“答案正确”，那么模型也许可以发现一些不完全像人的内部策略。作者明确担心，人类演示可能把模型限制在人类已有的认知模式中。([arXiv][1]) 从机器学习角度，这和 AlphaGo 非常像：如果你只让 AI 模仿职业棋手，它最多非常像优秀人类；但如果让它通过奖励自己探索，它可能走出职业棋手一开始觉得奇怪、最后却证明有效的棋。R1 的梦想也是类似的：**不要只教 AI 模仿我们的推理，看看它能不能为了正确答案自己搜索更有效的推理策略。**

## 07 · 从 R1-Zero 到可用的 R1

但纯 RL 的 R1-Zero 有一个明显问题：它**不好用**。虽然数学推理很强，可输出常常很乱，可能中英文混杂，可读性差，而且因为训练 reward 主要集中在可验证推理任务上，它在写作、开放问答等通用任务上也不够理想。论文明确指出 R1-Zero 存在 readability 和 language mixing 问题。([arXiv][1]) 这很像你培养出了一个奥数怪才：解难题特别强，但写作业过程潦草、说话跳跃，甚至一句中文夹一句英文。于是作者没有把 R1-Zero 直接当最终产品，而是在它的基础上设计了真正的 **DeepSeek-R1**。

DeepSeek-R1 的训练就不再是“纯 RL 一把梭”。作者采用了一个多阶段流程，可以粗略理解成：**先给一点好的开头，再让它自己探索；探索出好东西后，把这些东西整理成教材；最后再做一轮强化学习，让它既会推理又像正常助手。**第一步叫 cold start：先用少量高质量长链推理数据做 SFT，让模型至少知道一个清晰、可读的推理答案应该长什么样。第二步做面向推理的大规模 RL，让数学、代码、逻辑能力继续增长。然后作者从中筛选高质量样本，再加入大量非推理数据，组成大约 **80 万条监督数据**做第二阶段 SFT，最后再做一轮 RL，同时兼顾推理、helpfulness 和 safety。([arXiv][1]) 所以 R1 和 R1-Zero 的关系特别重要：**R1-Zero 是科学实验，用来证明纯强化学习能不能长出推理；R1 是实际模型，把这种能力和传统 SFT、偏好、安全训练重新结合起来。**

## 08 · SFT 与强化学习的分工

这也解释了为什么论文不能简单总结成“监督微调没用了”。恰恰相反，最终 DeepSeek-R1 仍然用了 SFT。真正被挑战的是另一个假设：**高级推理能力是否必须主要来自大量人工 CoT 教学？**R1-Zero 给出的证据是“不一定”。但是为了可读性、通用性和行为控制，监督数据依旧很重要。可以把两者的分工理解成：**RL 更擅长让模型探索‘怎样解决问题’，SFT 更擅长告诉模型‘怎样把结果用人类喜欢的方式表达出来’。**这和你读 GPT-4 时看到的 capability 与 alignment 区别其实是一脉相承的。

## 09 · 最终 R1 的能力与边界

再来看最终 R1 有多强。当前论文版本报告 DeepSeek-R1 在 AIME 2024 上 pass@1 大约 **79.8%**，MATH-500 达到 **97.3%**，Codeforces rating 约 **2029**，在多个推理 benchmark 上和当时的 OpenAI o1 处于接近水平；例如表中 o1-1217 的 AIME 2024 是 79.2%，R1 是 79.8%。([arXiv][1]) 这里仍然不要读成“R1 在所有方面都超过 o1”：不同任务结果不同，而且 benchmark 会受到评测设置影响。真正重要的是：**一个以 V3 为基础、通过公开描述的大规模 RL 管线训练出来的模型，证明了 inference-time reasoning + reinforcement learning 这条路线可以把数学和代码能力推到非常高的位置。**

## 10 · 推理时计算：另一条扩展轴

“inference-time compute”也是理解 R1 必须掌握的概念。以前 scaling 主要发生在训练期：模型参数从 1B 变 10B、100B，预训练 token 从几千亿变几万亿；模型一旦训练完，每道题通常直接回答。R1 代表的 reasoning model 则开始重视另一根杠杆：**同一个模型，面对更难的问题时，能不能在回答前花更多 token 思考，从而获得更好的结果？**这就像以前主要投资“把学生培养得更聪明”，现在又多了一个选择：“考试时给学生更多草稿纸和时间”。R1-Zero 在训练中自然出现越来越长的回答，就是一种信号：模型发现对于难题，多花计算探索、验证、回溯是值得的。([arXiv][1]) 所以现代 reasoning model 的 scaling 不再只有 **training-time compute**，还多了一条 **test-time / inference-time compute** 的轴。

但“思考越长越好”也不成立。论文指出 R1 的长链推理有时仍然会陷入错误逻辑，绕很久也走不出来。一个很直观的结果是：R1 在 AIME 2024 上单次回答约 79.8%，而如果允许独立生成许多不同推理路径，pass@64 可以达到 **90.0%**。([arXiv][1]) 这说明单条长思路仍然会走错，但如果允许模型尝试多个解法，总有更大概率撞到正确路径。这非常像搜索问题：推理模型不只是“储存知识”，而越来越像在答案空间里执行一种计算搜索。未来一个核心问题因此变成：**同样 10 万个推理 token，是让一条思路想 10 万 token，还是并行尝试 10 条 1 万 token 的思路，怎样分配最划算？**

## 11 · 蒸馏：把推理能力传给小模型

然后来到我认为 R1 论文第二个极其重要的结果：**distillation，蒸馏。**训练一个巨大的 R1 做长推理很贵，作者于是问：既然大模型已经通过 RL 找到了很好的思考方式，能不能让它把这些解题轨迹生成出来，再拿来训练更小的模型？他们用 DeepSeek-R1 生成、筛选出约 **80 万条样本**，再去 fine-tune Qwen 和 Llama 系列的小模型。令人吃惊的是，即使没有再对这些学生模型做 RL，单纯学习 R1 的高质量输出，也能得到非常强的推理能力。([arXiv][1])

这里可以把 R1 想成一个世界级数学老师。训练 R1 的过程很昂贵，相当于这个老师自己花几十年摸索出解题方法。但一旦他知道怎么解，就没必要让每个小学生重新花几十年通过 trial-and-error 独立发现微积分。老师可以写出几十万份高质量教材，学生直接学习。论文里最明显的例子是 DeepSeek-R1-Distill-Qwen-32B：AIME 2024 pass@1 达到 **72.6%**，MATH-500 达到 **94.3%**，GPQA Diamond 达到 **62.1%**，LiveCodeBench 达到 **57.2%**。([arXiv][1]) 更小的 1.5B、7B、14B 模型也出现了远超原本 instruction model 的数学推理能力。

## 12 · 自己探索，还是向强模型学习？

作者还专门做了一个非常有价值的实验：对同一个 Qwen2.5-32B，一条路线直接做大规模 RL，另一条路线直接蒸馏 R1。结果 **R1-Distill-Qwen-32B 明显强于他们直接做 RL 得到的 Qwen2.5-32B-Zero**；例如 AIME 2024 一个是 72.6%，另一个是 47.0%。([arXiv][1]) 这个结果告诉我们：**对于小模型来说，“自己从奖励中发现高级推理”可能太难；先让一个能力足够强的大模型探索，再把发现传给小模型，通常更经济有效。**但作者同时强调，如果目标是继续突破现有能力边界，而不仅仅复制已有能力，那么强 base model + 大规模 RL 仍然可能是必要的。([arXiv][1])

## 13 · 大模型探索，小模型继承

这其实形成了一套非常漂亮的“科研—教学”循环：**大模型负责探索，小模型负责继承。**大模型计算昂贵，但可以通过 RL 在答案可验证的问题上发现新的推理模式；找到以后，它生成大量高质量解答；这些解答成为下一批模型的 SFT 数据；小模型不用重新支付全部探索成本就能获得其中很多能力。你前面读 DeepSeek-V3 时看到 R1 reasoning distillation 被拿回去增强 V3，就是同一逻辑。它甚至可能形成一个循环：更强基础模型 → 更强 RL 推理模型 → 生成更好的数据 → 蒸馏回基础模型或小模型 → 再成为下一轮更强的起点。

## 14 · 没有成功的尝试

R1 论文还有一点特别值得欣赏：作者也写了**没成功的方法**。例如 Process Reward Model，也就是不是只看最终答案，而是给每一步推理打分，理论上听起来非常合理——错误一发生就纠正，岂不是比最后才知道答案错更好？但现实很困难：怎样可靠定义“一步”的边界？怎样大规模自动判断某一步到底正确？模型又很容易 exploit reward model。作者因此没有把 PRM 作为主要方案。另一个是 Monte Carlo Tree Search，MCTS，也就是像 AlphaGo 那样在推理树上搜索。它在数学题上理论上很诱人，但自然语言的搜索空间远比围棋难控制，扩展节点以后搜索空间爆炸，而且 value model 很难可靠评估中间状态，因此实验并没有得到预期效果。([arXiv][1]) 这些失败非常重要，因为它们说明“让模型多想”并不等于简单套用经典搜索算法就行。

## 15 · 从扩大模型到增加思考

如果现在把它放回你已经读过的整个发展史，会出现一条非常清楚的新阶段。**GPT-1：预训练可以得到通用能力；GPT-2：任务能力会从语言建模中自然出现；GPT-3：上下文可以指定任务；GPT-4：通用模型扩展到更广专业能力和多模态，同时重视对齐与安全；DeepSeek LLM：研究怎样科学 scaling；DeepSeek-V2/V3：研究怎样把超大基础模型训练和运行得更经济；DeepSeek-R1：开始研究已经拥有知识的模型，能否通过强化学习在推理时学会主动使用更多计算、自我检查和搜索，从而进一步提高复杂问题能力。**也就是说，故事开始从 **“scale the model”** 转向 **“scale the thinking”**。

这个变化非常关键。过去提升 AI 最直接的方法是“训练一个更大的模型”。R1 代表的方向则告诉你，未来模型能力可能由两个预算共同决定：**第一笔预算在训练时花，用来造一个足够强的基础大脑；第二笔预算在回答问题时花，让这个大脑根据题目难度决定想多久。**简单问题可能几百 token 解决，奥数题可能需要几千甚至几万 token 的搜索、验证和回溯。因此推理模型更像一个可以动态分配计算资源的系统，而不是固定做一次前向传播就结束。这也是为什么 R1 真正重要的不是“会写很长的思维链”，而是它展示了一种 **test-time compute scaling** 的可训练机制。

## 16 · 用一分钟讲给朋友听

如果现在合上论文，用费曼法要求一分钟讲给朋友听，我会这样说：**DeepSeek-R1 研究的是，能不能不先给 AI 几十万份人类写好的解题过程，只告诉它最后答案对不对，然后靠强化学习让它自己学会怎么思考。作者先做 R1-Zero，直接从 V3-Base 开始用 GRPO 强化学习；同一道题让模型尝试很多答案，答得比同组更好的就提高概率。结果随着训练，模型会自动使用更长的推理，开始出现检查、反思、重试和换策略等行为，AIME 2024 从约 15.6% 提高到 77.9%。但纯 RL 的模型输出很乱，所以真正的 R1 又加入 cold-start SFT、更多监督数据以及第二轮 RL，让它既会推理又更可读、更通用。最后，他们再把 R1 生成的高质量推理数据蒸馏给 1.5B 到 70B 的小模型，发现小模型也能继承大量推理能力，而且很多情况下比小模型自己从零做 RL 更有效。**([arXiv][1])

所以这篇论文我建议你最后只留下一个公式般的理解：**Pretraining gives knowledge，RL learns how to spend computation，Distillation transfers the discovered reasoning。**📖 用中文就是：**预训练让模型“知道东西”，强化学习让模型“学会怎么多想”，蒸馏再把大模型探索出来的思考方式教给小模型。**如果说 GPT-3 的关键转折是“不要每次为了新任务重新训练参数”，那么 R1 这一代的关键转折则是：**不要认为模型一次前向生成就是固定的智能水平——对于困难问题，可以让模型在推理阶段主动花更多计算，通过搜索、验证和自我修正换取更高正确率。**这就是从“把模型做大”走向“让模型学会思考更久”的那一步。
