# MEM：短期记细节，长期记要点

论文：MEM: Multi-Scale Embodied Memory for Vision Language Action Models（2026）

## 01 · 机器人记得刚才发生过什么吗？

这篇叫《MEM: Multi-Scale Embodied Memory for Vision Language Action Models》。如果把你前面一路读的 π0 → π0.5 → KI → RTC → π*0.6 串起来，这篇其实是在补机器人智能里一个极其基础、但前面一直没有真正解决的问题：**机器人会看、会听、会动、会从经验学习，但它到底会不会“记得刚才发生过什么”？**现实里的很多任务根本不是看到当前一帧就能决定下一步。机器人清理厨房时，要记得哪个台面已经擦过、盘子有没有打过肥皂、冰箱门是不是自己刚打开的；做三明治时，要记得已经放过哪些食材；抓筷子失败以后，要记得“刚才这样抓不行”，然后马上换一个策略。作者的核心观点是：**机器人记忆不是一个尺度的问题，而是多个时间尺度、多个抽象层次的问题。**最近几秒最好保留细致视觉，因为它能处理遮挡、失败和动作细节；几分钟前发生的事情则没必要保存所有像素，只需要压缩成“我已经把三个碗放进右上柜子”这样的语义摘要。MEM 就是把这两种记忆组合起来：**短期用视频记忆，长期用语言记忆。**论文把它接到 π0.6 上，得到 π0.6-MEM，并展示它能处理需要长达 15 分钟记忆的任务。

## 02 · 不同时间尺度，不同记忆表示

先用费曼法想象一个人做饭。假设你刚刚伸手拿杯子，杯子被手臂挡住了。这个时候你需要的是非常“低级但精细”的记忆：半秒前杯子到底在什么位置、手刚才从哪个方向靠近。你不会在脑子里把它总结成一句“我曾经看到一个杯子”；你需要保留视觉运动细节。可是如果你已经做饭十分钟，现在要判断“黄油到底加没加”，你就完全没必要回放过去十分钟所有视觉帧，只要记住一句“黄油已经加了”就够了。论文认为过去很多 robot memory 方法的问题，就是想用一种表示包打天下：全存视频太贵，全用语言又丢精细空间信息，只存 proprioception 只能记自己身体而记不住外部世界，只留 keyframes 又可能错过运动和遮挡细节。MEM 的关键洞察就是：**不同时间尺度应该用不同“压缩率”的记忆。**短期信息密度高，所以保留视觉；长期只保留语义。

## 03 · 语言记忆：压缩长期任务历史

MEM 的长期记忆叫 **language memory**。它不是简单把所有历史指令不断往 prompt 后面拼，而是让高层策略自己维护一份不断更新的自然语言摘要。比如当前 memory 是“我已经把盘子放进柜子，并移动到台面前”，机器人刚刚又成功拿起一个碗，那么下一次 memory 可以更新成“我已经把盘子放进柜子，移动到台面，并拿起了一个碗”。更重要的是，它还会主动**忘掉不重要细节**。比如过去分别放了浅绿碗、深蓝碗、黄色碗，长期真正有用的也许只是“我已经把三个碗放进右上柜子”。作者用现成 LLM 根据 episode 里的 subtask 和成败情况生成这种训练用摘要，然后训练高层 policy 学会自己更新 memory。 这其实很像人类做笔记：不是把一天发生过的每句话逐字抄下来，而是不断压缩成“以后还会影响决策的东西”。

为什么不能最简单地把历史 subtask 全部拼起来？论文专门做了这个消融，结果这种 **naive text memory** 明显更差。原因特别有意思：训练 demonstrations 往往很干净，一项任务通常一次就成功，比如“拿起碗 → 放进柜子”；但真正部署时机器人可能连续失败三次，于是历史会变成“拿起碗 → 拿起碗 → 拿起碗 → 放进柜子”。如果模型训练时几乎没见过这种重复历史，推理时就产生很大的 distribution shift。MEM 的语言摘要则可以选择：失败时先不更新长期记忆，只有真正拿起来以后才写进“我已经拿起碗”。于是它不是简单“记得更多”，而是**只把已经具有未来价值的事件写进长期记忆**。 这点其实很深：好的记忆系统不只是存储系统，也是一个信息筛选系统。

## 04 · 视频记忆：保留近期视觉细节

短期记忆则完全不同。作者认为最近几秒到几十秒内的信息，必须保留密集视觉，因为机器人需要理解动力学、遮挡和最近失败。可如果你把过去 10、20 张图每张都独立送进 VLM，计算会爆炸。论文图里很直观：随着帧数增加，普通做法的推理时间很快超过机器人实时控制可以接受的几百毫秒。MEM 因此设计了一个**视频编码器**：它从普通 ViT 出发，不是把所有时间、空间 patch 做一次巨大的联合 attention，而是把空间 attention 和时间 attention 分开；大约每四层加入一次 causal temporal attention，让同一个图像 patch 在不同时间之间交流。更关键的是，在高层 ViT 里把过去 timestep 的 patch token 直接丢掉，只把“当前帧的表示”送进后面的 VLA backbone，但这个当前表示已经通过前面的 temporal attention 吸收了历史。 用费曼法说：不是把过去十几张照片全部摆在大脑桌面上，而是先让一个“视频秘书”看完，然后交给大脑一张已经包含历史信息的当前摘要。

这个视频编码器还有一个很漂亮的工程特点：**几乎不需要额外学习参数。**它主要改变原有 ViT 的 attention pattern，再加固定的时间位置编码，所以可以直接从预训练视觉模型初始化；如果输入只有一张图，它的初始化行为还能和原来单图 VLM 保持一致。 这意味着作者不是扔掉 π0.6 原来的视觉能力，重新训练一个大视频模型，而是尽可能保留已有视觉知识，再加上“跨时间看”的能力。这个设计和你前面读 KI 时的思想很一致：**不要为了获得新能力，把预训练模型原本好不容易学来的能力一起破坏。**

## 05 · 为 π0.6 接入多尺度记忆

π0.6-MEM 本身沿用了你前面熟悉的很多结构：Gemma 3 4B 的 VLM backbone、FAST 离散动作预测、860M 的 flow-matching action expert，而且 action expert 的梯度仍然不回传污染 VLM backbone，也就是 Knowledge Insulation 那套原则。它最多看四路相机，还把历史 proprioceptive state 通过连续 embedding 输入，而不是把每个历史关节状态都转成大量文字 token。预训练时每次使用 6 个 observation，也就是当前帧加过去 5 帧，每帧间隔 1 秒；到了 post-training，模型居然可以把视觉记忆扩展到最多 18 帧、总计约 **54 秒**。 这里非常像语言模型 long-context 的一种现象：训练时不一定要见过最终最长上下文，后训练时仍可以扩展一定长度。

## 06 · 长任务为什么需要两种记忆

然后看最重要的实验：**为什么机器人一定需要记忆？**作者设计了两个长达 15 分钟左右的任务。第一个叫 Recipe Setup：用户告诉机器人某道菜需要哪些食材和厨具，以及它们分别在哪，机器人要去冰箱、抽屉、柜子里一个个找出来，再摆到指定位置，最后还得记得把自己打开的门和抽屉关上。第二个是 Clean Kitchen：机器人要收纳物体、擦台面、给盘子加肥皂、用流水清洗、把盘子放进沥水架。这里很多东西从当前画面根本看不出来——比如这个盘子的背面刚才洗过没有、哪个区域已经擦过、某扇柜门是不是自己之前打开的。论文发现没有 memory 的 π0.6 在这些任务上明显吃力，而完整 MEM 明显更强；同时去掉短期 video memory 或去掉长期 language memory，都会明显下降。 这正好支持作者最核心的判断：**长期语义记忆和短期视觉记忆不是互相替代，而是负责完全不同的问题。**

## 07 · 记住失败，现场改变策略

短期 memory 还有一个特别有意思的作用：它让机器人出现了某种 **in-context adaptation**。比如桌子高度和训练分布不一样，机器人第一次抓筷子失败了；没有记忆的 policy 下一次看到的当前画面差不多，很可能继续重复同样的抓法。MEM 则保留了之前几秒的视觉历史，所以能知道：“刚才我从这个高度下去失败了。”作者用人类 correction 数据训练以后，机器人可以现场调整抓取高度。另一个任务是开冰箱门：一开始不确定门朝哪边开，第一次拉错以后，有 memory 的机器人可以换方向，而不是不断重复同样错误。论文报告 Pick Up Chopstick 的 success rate 因 memory 提高约 **11 个百分点**，Open Fridge 更是提高约 **62 个百分点**。 这其实是很重要的一步：记忆不只是为了“回忆任务进度”，还可以让模型在参数完全不更新的情况下，**根据刚刚发生的失败临场改变策略**。

如果你把这一点和 GPT-3 的 in-context learning 放在一起，会发现很有趣的对应关系。GPT-3 是在上下文里看到几个文本例子，然后不改参数地改变答案方式；MEM 则是在上下文里看到**自己刚才真实做过的动作和失败结果**，然后不改参数地改变机器人操作方式。一个是语言上下文，一个是 embodied context。可以把它叫成一种非常朴素的“身体版 in-context learning”：**刚才失败本身就是一个 demonstration，模型如果记得它，就能利用它。**这也是为什么短期视觉记忆必须足够密，如果只留一句“我失败了”，可能并不知道究竟是抓得太高、太低，还是门拉错方向。

## 08 · 与简单记忆方法的比较

论文还拿 MEM 和几种简单 memory 方法正面对比。一个 baseline 是 Pool-Memory，把历史视觉特征做 average pooling；另一个是 Proprio-Memory，只记机器人自身状态。作者设计了 Swap 3 Mugs、Find Object、Unpack Groceries、Scoop Coffee、Grilled Cheese、Window Cleaning 等任务，分别考位置记忆、遮挡、计数和长程视觉上下文。结果很符合直觉：Proprio-Memory 在只需要记“自己身体刚才怎样”的任务里还可以，但如果要记“哪个抽屉里有东西”，就不够；Pool-Memory 压得太狠，在简单几 bit 的记忆任务还能工作，一碰到多个物体、长期环境状态就更容易丢信息；**MEM 是唯一一个在所有这些核心 memory 能力上都比较稳的方案。**

## 09 · 使用记忆本身也需要预训练

这里还出现一个非常值得记住的结论：**memory capability 本身也需要 pretraining。**作者做了一个“post-train only”版本：先用普通 π0.6 完成预训练，到了最终目标任务才突然把视频 memory 模块接进去。结果明显比从预训练阶段就带 memory 的 MEM 差。即便两者都初始化自同一个强 π0.6，真正从一开始就见过多样机器人数据和互联网视频、并学会“怎样利用历史帧”的版本，后面更能用好长记忆。 这点和你刚刚读 Human-to-Robot Transfer 的“emergence”非常像：**不是给模型多一个输入接口，它就自动知道怎么用；使用记忆本身也是一种能力，需要规模化、多样化训练才能形成。**

更有意思的是，预训练时只有约 5 秒左右的视觉历史，post-training 时却可以扩展到接近 1 分钟，而且仍然获得明显收益。 这意味着模型似乎不是机械背“第 3 帧和第 4 帧之间的固定模式”，而是真的学到了某种跨时间提取信息的方法。这一点对未来很重要，因为真机器人长期任务不可能预训练时覆盖所有可能的 memory horizon；真正可扩展的系统应该学会一种“怎么读历史”的技能，而不是死记某个固定窗口。

## 10 · 记忆会不会干扰灵巧操作

还有一个非常实际的问题：加 memory 会不会把原本灵巧操作能力搞差？过去不少工作发现，给 policy 加长历史以后会出现 causal confusion——模型开始错误地复制之前动作，或者被大量旧信息干扰，导致普通任务反而变差。MEM 专门测试了一批本来不怎么需要长期记忆的 dexterous task，包括 Table Bussing、Shirt Folding、Clean Up Counter、Make Bed、Dishes to Sink、Batch Folding、Box Building。结果完整 MEM 大体能够匹配普通 π0.6 的水平，并没有因为“会记东西”就明显牺牲原本动作能力。 作者把这一部分归因于大规模、多样化预训练：训练数据包含不同速度、不同质量、不同控制频率的机器人 episode，还有互联网视频，因此模型不太容易学成“看到旧动作就机械复制”。

## 11 · 从经验学习与从上下文学习

把它和 π*0.6 联系起来就更有意思了。π*0.6 解决的是：**机器人能不能从一次次 deployment 经验里更新参数，下一版变得更强。**MEM 解决的是另一个时间尺度：**在这一条 episode 里，不更新任何参数，机器人能不能记住几十秒甚至十几分钟前发生的东西，让当前这一版立刻做得更聪明。**所以可以把两者分成两种学习：π*0.6 是跨 episode 的 learning from experience；MEM 是 episode 内的 learning from context。前者像“昨天犯了错，今晚训练以后明天变强”；后者像“我五秒前刚犯过一次错，这一次就别再犯”。真正强的机器人其实两种都需要。

## 12 · 实时执行与多尺度时间问题

再和 RTC 放在一起看，又能看到 Physical Intelligence 这一整套系统越来越完整。RTC 说：模型推理慢没关系，身体执行和大脑思考可以并行；MEM 说：大脑思考时别只看当前世界，要把刚才发生的事情一起纳入。于是现实机器人开始同时面对三个时间问题：**毫秒级，动作必须实时连续；秒级，需要视觉记忆处理遮挡和纠错；分钟级，需要语义记忆维持任务进度。**MEM 最有价值的地方，就是它不试图用一个巨大 context window粗暴解决三个尺度，而是明确承认：**时间尺度不同，最合适的表示也不同。**

## 13 · 让高层规划拥有任务日记

如果再把它和 Hi Robot / π0.5 联系起来，语言 memory 的作用也会更清楚。Hi Robot 和 π0.5 已经会产生“pick up bowl”“put plate in cabinet”这种高层 subtask；MEM 做的相当于再加一层元信息：**哪些 subtask 已经真的完成了、哪些失败了、哪些历史事实未来还重要。**所以高层 policy 不再只是每次看当前画面然后重新规划，而是携带一份压缩过的“任务日记”。这让 hierarchy 从“有 planner”进一步升级成“有 stateful planner”。

## 14 · 从单次任务到长期记忆的展望

这篇论文还有一个很值得长期思考的方向：作者最后明确说，目前 memory 主要跨越一个 episode，未来希望扩展到**几周、几个月甚至几年**。 如果真的做到，那机器人记忆的含义就会发生变化：不再只是“刚才这个盘子洗过没有”，而是“这个家里主人通常把杯子放哪里”“上周这扇柜门比较卡”“这个人喜欢咖啡加两勺糖”。到那一步，robot foundation model 就会开始从“一次任务中的记忆”走向真正的**持续个人化和终身经验积累**。当然这篇还没有做到，只是把多尺度 memory 的基本 architecture 先建立起来。

## 15 · 用一分钟讲给朋友听

如果现在合上论文，用费曼法一分钟讲给朋友听，我会这样说：**现在很多机器人 VLA 每次只看当前画面，所以它可能会忘记十秒前自己抓失败过，也会忘记十分钟前已经洗过哪个盘子。MEM 认为短期和长期记忆根本不该用同一种格式。最近几秒需要保留密集视频，因为机器人要处理遮挡、动作细节和失败纠正；几分钟前只需要保留语义摘要，比如“我已经把三个碗放进柜子、盘子已经加了肥皂”。所以它给 π0.6 加了两个记忆系统：一个高效视频编码器负责短期视觉历史，一个不断更新和压缩的自然语言 memory 负责长期任务历史。结果机器人可以完成需要长达 15 分钟记忆的清厨房、准备食谱和做三明治任务，还能因为记得刚才失败的抓法，现场换策略。更重要的是，实验说明“会使用记忆”本身也需要预训练，不是把更多历史帧塞进去就自动会用。**

所以这一篇我建议最后只记一句话：**Short-term memory should remember what the world looked like; long-term memory should remember what mattered.** 📖 中文就是：**短期记忆保存“刚才到底发生了什么细节”，长期记忆只保存“以后还需要知道什么”。**如果 π*0.6 让机器人开始从自己的经验里长期变强，那么 MEM 补上的就是另一种更即时的智能：**不用重新训练，机器人也应该因为记得自己的过去，而在这一刻做出不同的决定。**
